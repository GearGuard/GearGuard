1) Download the archive or clone the project using git
2) Run bellow commands on terminal
    ``` 
    composer init
    composer update
    composer require vlucas/phpdotenv
    ```
3) Create a ``.env`` file and follow the ``.evn.example`` file format the database.
4) Go to the public folder 
   ``` 
   cd public
   ```
5) Start php server by running command 
   ```
   php -S 127.0.0.1:8080
   ```
   or
   ``` 
   php -S localhost:8080
   ```
6) Open browser and run ``http://localhost:8080``
